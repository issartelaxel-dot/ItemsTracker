# Polices locales

IBM Plex Sans et Sora : fontes variables WOFF2 latines, toutes les graisses normales.
IBM Plex Mono : WOFF2 latines, graisses 400 et 500.

Sources : paquets Fontsource 5.3.0 (`@fontsource-variable/ibm-plex-sans`,
`@fontsource-variable/sora`, `@fontsource/ibm-plex-mono`). Les licences OFL
accompagnent les fichiers. Le sous-ensemble latin couvre les accents français.
Ces fichiers sont versionnés dans le projet ; le build ne les télécharge pas.
